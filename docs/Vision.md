# Vision

Create an Apple/Stripe-quality static portfolio — a site people remember after
closing the tab.

## What this site is

A cinematic, dark, editorial experience that tells one story in one scroll:
**Nabhan builds production software for real Indonesian businesses.** Every
section is a scene (see `docs/Animation-Guide.md`); every claim is verifiable
(live URLs, public repos, an examined thesis, hardware in a field).

## Non-negotiables

1. **Storytelling, not scrolling** — the narrative arc is fixed:
   arrival → who → how I think → proof → breadth → capability → history → invitation.
2. **Static forever** — Jekyll on GitHub Pages, zero servers, zero databases.
3. **Motion is communication** — no decorative animation; reduced-motion and
   no-JS users get the complete story.
4. **Truth over polish** — dead products are removed, simulated numbers are not
   metrics, nothing is claimed that can't be checked.
5. **Lighthouse ≥95 everywhere** — beauty that costs performance isn't beauty.

## Success criteria

A recruiter understands who Nabhan is in 10 seconds; an engineer respects the
architecture sections in 2 minutes; a client finds the email link before either
gets bored.
